## Cara menjalankan (bisa diulang sebelum tiap event)

```bash
npm run qa
```

Perintah ini menjalankan, berurutan:

1. `svelte-check` (0 error);
2. `vitest` (19 tes logika frontend);
3. `cargo test` (52 tes Rust, termasuk tes end-to-end PORPROV).

Untuk uji layar manual, ini menyalakan router asli + frontend build di http://127.0.0.1:8010 dengan salinan DB dan media:

```bash
cd src-tauri && CARGO_TARGET_DIR=target/qa-serve cargo test --lib qa_serve_for_manual_testing -- --ignored --nocapture
```

Pakai `npm run build` dulu.

## Bug yang ditemukan dan sudah diperbaiki

1. **`cargo test` mengubah database turnamen asli** (kritis).
   - `test_draw_event9_real` menjalankan undian langsung di `tournament_data/db.sqlite3`.
   - Tes buku festival juga me-mount file asli.
   - Tes reset menyalin file ke folder `tournament_data/`.
   - Sekarang semua tes memakai `test_support::real_db_copy()` (snapshot di folder temp).
2. **Pemain pengganti yang diketik namanya di partai beregu menjadi "tim" baru** (tinggi).
   - `assign_bout_athletes` membuat atlet di kategori beregu tanpa kode `MEMBER_`.
   - Akibatnya jumlah peserta bertambah, dan undi ulang akan menaruh orang itu di bagan sebagai tim.
   - Sekarang pengganti mendapat `MEMBER_<kode tim>_SUB`.
3. **Tablet juri menampilkan "Partai Ini Adalah Kumite" untuk partai kata** (tinggi).
   - Terjadi bila tablet tersambung sebelum control panel menyiarkan state, atau setelah host restart.
   - Sebabnya: state dari DB menganggap kata hanya bila nama kata sudah dipilih.
   - Sekarang ditentukan dari kategori (aturan sama dengan `isKataCategory`), dan nama kategori ikut dikirim.
4. **Nomor tatami ganda diterima** (sedang). "Tatami 1" kedua di event yang sama, atau tatami 0, dulu diterima. Semua layar LAN mencari tatami lewat nomornya, jadi tidak jelas partai mana yang tampil. Sekarang ditolak saat dibuat maupun saat ganti nomor.
5. **Scoreboard menampilkan "AMBRILINDO OPEN KARATE CHAMPIONSHIP"**, bukan nama event (sedang). Control panel yang dibuka dari portal/QR tidak memuat nama event. Sekarang nama diambil dari event bagan, dan placeholder-nya disembunyikan scoreboard.
6. **Logo kontingen hilang di scoreboard setelah host restart** (kecil). State dari DB mengirim `logo: null`, sehingga scoreboard menampilkan bendera INA sampai control panel siaran lagi. Sekarang logo ikut dikirim.
